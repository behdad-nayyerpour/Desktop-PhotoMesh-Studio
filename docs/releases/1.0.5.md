# Lens2Mesh 1.0.5

Complete offline Windows x64 installer. Download **Lens2Mesh_Setup_1.0.5.exe**;
close the application, then run Setup. Choose the existing installation folder
to upgrade. Keep projects, source photographs and results outside that folder.
Verify the download against the accompanying SHA-256 file.

- New Lens2Mesh name and artwork, with existing projects and settings supported.
- Photo GPS/calibration controls and explicit coordinate and height references.
- Ground/non-ground classification, ground-only DTM and LAS/LAZ exports.
- Exact mesh cross sections including overhangs, floors, vertical faces and gaps;
  surface-bound 3D line, editable handles, slope picks and equal-axis Fit 1:1.
- Improved completed-product display, progress reporting and script errors.
- Offline learned matching runtime and fixes for Unicode native-processing paths.
- Updated complete 119-page English manual, available offline in Help and here.

The installer includes Python, processing engines and offline models. Dense
reconstruction requires a compatible NVIDIA GPU/driver; CPU alignment and
meshing workflows remain available. The Windows installer is unsigned.
