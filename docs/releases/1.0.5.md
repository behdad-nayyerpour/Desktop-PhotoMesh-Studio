# Lens2Mesh 1.0.5

**Base:** `Lens2Mesh_Setup_1.0.5.exe` — about **599 MB**, **64% smaller**.
Includes Python, engines and offline models. Close the app before installation;
choose its existing folder to upgrade. Keep projects/photos outside that folder.

Highlights: GPS/calibration, ground classification, DTM, LAS/LAZ, exact mesh
sections with Fit 1:1, Unicode-path fixes and improved progress.

**Optional NVIDIA add-on:** `Lens2Mesh_NeuralGPU_Addon_1.0.5.exe` accelerates
ALIKED/LightGlue on GPU; both use CPU without it. Install into the same folder
with the app closed. Standard COLMAP GPU remains in the base. Compatible hardware
and driver are required; no CUDA Toolkit installation is needed.

SHA-256 checksums and the updated 119-page manual are included. Installers are
unsigned. Personal/educational non-commercial use is permitted; commercial use
requires permission. Third-party licences apply.

Point selection/deletion and remaining native source/build-provenance work are
deferred to 1.0.6; this is not redistribution clearance.
